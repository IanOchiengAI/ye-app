## ✨ Why Youth Educated?

1. **Localized Intelligence**: We don't just use generic AI. **Rafiki** understands Kenyan slang, local career paths, and the specific challenges of the CBC curriculum.
2. **M-Pesa Native**: We've removed the greatest barrier to premium content. If you have an M-Pesa pin, you have access.
3. **PWA Technology**: Our app is a **Progressive Web App**. Install it directly from your browser, enjoy offline support (coming soon), and save storage space.

---

## 🛠️ Technical Stack

* **Framework**: Next.js 14 (App Router)
* **Styling**: Custom "Clean SaaS" Design System with CSS Modules.
* **Payments**: Safaricom Daraja API (M-Pesa Express).
* **Backend**: Firebase (Auth & Firestore) with a robust "Mock Mode" for development.
* **PWA**: Service Workers for offline caching and high performance.

## 🚀 Development & Deployment

### Local Setup

1. `git clone https://github.com/IanOchiengAI/ye-app.git`
2. `npm install`
3. `npm run dev`

### Deployment to Vercel (To get your own Live Link)

The easiest way to get a live URL like the ones above is to push your repo to GitHub and import it into [Vercel](https://vercel.com).

1. Connect your GitHub account.
2. Select the `ye-app` repository.
3. Add your M-Pesa credentials to the **Environment Variables** in the Vercel dashboard.
4. **Deploy!**
