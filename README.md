# Youth Educated 🌍 ✨

**Empowering the Next Generation of African Leaders**

> "Talent is evenly distributed, but opportunity is not. We are bridging that gap."

---

## 🚀 Overview

**Youth Educated** is a next-generation EdTech platform designed specifically for the Kenyan context. We combine life-skills curriculum, human mentorship, and AI-powered guidance to prepare youth for the future of work and life.

Whether you are a student looking to grow, a school administrator tracking impact, or a sponsor changing lives—this platform connects the ecosystem.

---

## 🌟 Portals & Dashboards

We have built dedicated experiences for every stakeholder in the education ecosystem.

**[Go to Student Dashboard](/dashboard)**

## ✨ Key Features

### 1. 🏆 Gamified Growth (New!)

We believe learning should be engaging.

* **XP System**: Earn points for every lesson and interaction.
* **Free vs. Premium Tiers**: Unlock advanced stats and global rankings.
* **Badges**: Earn recognition for "Financial Wizardry", "Community Legend", and more.

### 2. 🤖 Rafiki AI (The "Friend")

A localized AI companion that understands the context.

* *"Habari? How can I help you with your KCSE prep today?"*
* Voice-enabled for accessibility.
* Trained on CBC curriculum and Kenyan career paths.

### 3. 📱 Mobile First (PWA)

Built for Africa.

* **Installable**: Add to Home Screen directly from the browser.
* **Offline-Ready**: (Coming Soon) Download content for low-data environments.
* **Lightweight**: Optimized for low-end Android devices.

## 🛠️ Technical Stack

* **Framework**: Next.js 14 (App Router)
* **Styling**: CSS Modules (Custom "Clean SaaS" Design System)
* **Authentication**: Firebase Auth (with Custom Mock Mode for Dev)
* **Database**: Firebase Firestore (Mocked for Demo)
* **Deployment**: Vercel Ready

## 🚀 Getting Started

1. **Clone the repo**

    ```bash
    git clone https://github.com/your-org/youth-educated.git
    ```

2. **Install dependencies**

    ```bash
    npm install
    ```

3. **Run the development server**

    ```bash
    npm run dev
    ```

4. **Open the App**
    Visit [http://localhost:3000](http://localhost:3000)
