# 🚀 Deployment Guide: Youth Educated App

This guide walks you through deploying your application to **Vercel**.

## Prerequisites

1. **Vercel Account**: [Sign up here](https://vercel.com/signup).
2. **GitHub Repo**: You already have this set up! ✅

---

## Step 1: Push Changes

Open your terminal and run:

```bash
git add .
git commit -m "feat: Add Rafiki AI and optimize for Vercel"
git push
```

## Step 2: Deploy to Vercel

1. **Go to Dashboard**: [vercel.com/dashboard](https://vercel.com/dashboard)
2. **Add New Project**: Import your `ye-app` repository.
3. **Environment Variables**:
    * Add `NEXT_PUBLIC_GA_ID` = `G-XXXXXXXXXX`
4. **Deploy**: Click **Deploy** and wait ~1 minute.

---

## Step 3: Verify

1. Visit your new `https://ye-app.vercel.app` URL.
2. Check the "Meet Rafiki" section!
3. Test the AI chat.

**🎉 You're Live!**
